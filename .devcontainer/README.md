# Live demo in GitHub Codespaces (free)

The system installs itself the first time (about 5 minutes) and then runs on port **8000**.

1. Wait until the terminal shows **"College ERP live at: https://…app.github.dev"**.
2. Open the **PORTS** tab: port 8000 should say **Public**. If it says *Private*: right-click → *Port Visibility* → *Public*.
3. Copy that address — it is your live link (browser, phone, and the Android app: *Server · Change*).
