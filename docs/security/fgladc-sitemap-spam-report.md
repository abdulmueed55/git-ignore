# fgladc.edu.pk — spam links found in the sitemap

Checked on 20 November 2026.

## What was found

`https://www.fgladc.edu.pk/sitemap.xml` lists **35 URLs, and every one of them is spam**: online casinos and slot machines ("gadbet"), poker, sports streaming and unprescribed medicines (generic Viagra, chloroquine, PhenQ, Periactin). Not a single real college page is in the sitemap.

When checked, all 35 URLs returned **404 Not Found**. The spam pages have been deleted, but the sitemap that advertises them to Google is still on the server.

This is a classic **SEO spam injection**. Someone had write access to the hosting account (`/home/fgladcedu/public_html`), uploaded the pages and planted the sitemap so that Google would index them under the college's `.edu.pk` domain.

Also: the Downloads page's HTML source contains PHP error messages that reveal the server path (visible with View Source, not on screen):
`Notice: Undefined variable: title in /home/fgladcedu/public_html/showpage.php on line 216`

## What the college's IT person should do now

1. **Replace `sitemap.xml`** with one that lists only real pages, or delete it.
2. **Assume the attacker can still get in.** Deleting the pages does not remove the way they got in.
   - Change the cPanel, FTP, database and website-admin (`mylogin.php`) passwords.
   - Look for unknown PHP files, especially in `img/`, `upload/`, `images/` and in folders named `Finance`, `Inbox`, `Projects`, `Records` or `public_html` inside `public_html`.
   - Check `.htaccess` for redirects you did not add.
3. **Turn off on-screen PHP errors** (`display_errors = Off`) so server paths are not shown to visitors.
4. **Clean up Google:** add the site to Google Search Console, remove the spam URLs (Removals → New request), submit the clean sitemap, and check Security issues.
5. Search Google for `site:fgladc.edu.pk casino` and `site:fgladc.edu.pk viagra` after a few days to confirm nothing is left.

The new website and ERP in this repository do not reuse any code from the old site, so moving to them also removes this attack surface.
